# 标中 · AI 招投标编制平台

[标中官网](https://bzai.work/)面向投标编制人员，围绕招标文件要求组织技术方案、复用已有知识资产，并在提交前检查关键响应、条款与格式风险。

## 从哪里开始

- [技术方案编制](https://bzai.work/features/technical-plan/)：按招标要求组织大纲、章节正文和最终文档。
- [投标文件检查](https://bzai.work/features/bid-check/)：集中定位需要人工确认的响应与格式问题。
- [投标实务指南](https://bzai.work/guides/)：从阅读招标文件到提交前复核的参考资料。
- [关于标中](https://bzai.work/about/)：了解产品定位与使用边界。

生成和检查结果仅供投标编制参考，最终内容以招标文件及人工审核为准。

运营主体：国能智联（厦门）科技有限公司。

本仓库仅用于公开介绍标中及指向官网，不包含平台源代码或用户数据。
