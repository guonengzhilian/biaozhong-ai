# 标中｜AI 标书制作、技术方案编制与投标文件检查

[标中](https://bzai.work/)是面向投标编制人员的 AI 招投标辅助平台。围绕招标文件要求，帮助用户组织技术方案、复用已有知识资产，并在提交前检查投标文件中的响应遗漏、条款偏差和格式风险。

## 可以用标中做什么

- **技术方案编制**：依据招标文件组织技术标大纲和章节正文，支持继续编辑、复核和导出。[了解技术方案编制](https://bzai.work/features/technical-plan/)
- **投标文件检查**：比对招标要求与投标响应，定位需要人工确认的遗漏、偏差及格式问题。[了解废标项检查](https://bzai.work/features/bid-check/)
- **知识资产复用**：在编制过程中复用已确认的模板、素材和企业知识，减少重复整理。

## 从哪里开始

1. 查看[标中官网](https://bzai.work/)了解平台与使用入口。
2. 阅读[投标实务指南](https://bzai.work/guides/)，了解招标文件阅读、技术方案编制和提交前复核的常见问题。
3. 按项目需要使用[技术方案编制](https://bzai.work/features/technical-plan/)或[投标文件检查](https://bzai.work/features/bid-check/)。

标中提供的是编制和检查辅助，不承诺自动中标，也不能代替投标人的专业判断。生成内容和检查结果应以实际招标文件为依据，由用户在提交前人工核对。更多说明见[关于标中](https://bzai.work/about/)。
